## 调用及失败信息

`call_model` 返回模型文本和脱敏 `CallInfo`，记录模型名、UTC 开始时间、耗时、HTTP 状态、成功状态、错误码和接口实际提供的用量。未提供用量时为 `null`。HTTP 调用元数据由 `app.services.llm_client` 的 INFO 事件 `llm_http_call` 输出；计划校验由 `app.services.planning` 的 INFO 事件 `llm_plan_validation` 单独记录，接入方可启用这些 logger。冒烟脚本也直接输出脱敏元数据。

`CallInfo.success` 仅表示 HTTP 和 Chat 响应格式成功，不能单独当成计划生成成功。只有 `generate_plan` 成功返回，且计划校验事件成功，才能计为有效计划；冒烟脚本使用 `plan_validated` 明确区分。非法计划抛出 `LLM_OUTPUT_INVALID`，不会用固定计划替代。

使用普通 `/chat/completions`，没有服务端 JSON 模式、供应商专用扩展参数或自动重试。`timeout=40.0` 是 HTTPX 的连接、读取、写入和连接池等待超时配置，并非整个请求的严格墙钟截止时间。参见 [HTTPX 超时文档](https://www.python-httpx.org/advanced/timeouts/)。
