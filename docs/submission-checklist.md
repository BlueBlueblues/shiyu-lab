### 1.2 报名入口与标准流程【官网·FAQ Q8】

唯一官方报名入口：<http://aiedu.caet.org.cn>

标准流程：**账号注册 → 选定组别 + 细分赛道 → 填报团队信息 → 下载申报表签字盖章 →
上传全套材料 → 提交完成申报。** 注册与上传可以分次进行。

本团队组别/赛道：**大学生 AI 创新创业组 → 大学生 OPC 创新创业 AI Agent 赛道**。

### 1.3 团队与申报规则

- 个人和团队均可参赛；**团队规模最多不超过 5 人**【官网·FAQ Q4】。附件1 未另设人数上限【附件1】。
- **团队须确定 1 名主持人**，统筹申报、沟通、材料提交全流程【官网·FAQ Q4】；总纲 §1.2 表述为「确定 1 名负责人」【总纲转引】。
- 可以跨校 / 跨单位组队【官网·FAQ Q5】。
- **每个赛道（主持人）限选一个赛道申报，不得多头申报、重复申报；同一作品禁止跨组别、跨赛道重复提交**【官网·FAQ Q6】，与【总纲转引·第6页】一致。
- 是否协会会员均可报名；欢迎报名过程中注册成为协会会员【官网·FAQ Q3】。
- **报名费、教程全部免费**；决赛差旅自理【官网·FAQ Q2】。
- 奖项为**行业性奖项**，不是政府行政奖励【官网·FAQ Q7】。

### 1.4 材料规格【官网·FAQ Q10、Q12】，与【总纲转引·第7页】一致

| 材料 | 是否必交 | 格式与限制 |
| --- | --- | --- |
| 申报书及承诺书 | 必交 | PDF 扫描件；是否需要盖章见第 2 节 |
| 作品介绍 | 必交 | PDF；页数/大小额外限制【待核验】 |
| 演示视频 | 必交 | **MP4，≤10 分钟，≤500MB**；建议分段：概述 ≤2 分钟、核心场景演示 ≤6 分钟、效果总结 ≤2 分钟；可用「PPT + 录屏 + 解说」 |
| 支撑材料 | **选填** | PDF / ZIP，**总大小不超过 100M**；本团队按 ≤100MB 控制 |

### 1.5 内容要求

**作品介绍必须包含的字段**

- 【附件1·第2页】作品名称、应用场景、目标用户、核心功能、**AI Agent 设计思路**、
  **OPC 式实践体现**、创新点、应用价值及后续优化方向。
- 【总纲转引·第7页】作品名称、**3～5 个关键词**、概要、教育痛点、技术创新、落地场景、应用成效。

→ 两份要求合并执行：作品介绍按 **名称 → 3～5 关键词 → 概要 → 应用场景/目标用户 →
教育痛点 → 核心功能与流程 → AI Agent 设计思路 → OPC 实践 → 创新点 → 应用价值 →
应用成效 → 后续优化** 的顺序覆盖，两侧字段都不遗漏。

**产品形态是硬要求**【附件1·第1～2页】

- 「作品不得仅停留在概念方案、静态页面或 PPT 展示」，应具备**可演示、可体验的产品形态**
  （网页端、移动端、小程序、智能体平台应用、低代码应用等）。
- 要避免「仅展示一个普通 AI 问答工具或单一功能页面」。
- 对本项目的含义：必须有一条**真的能点、能填、能出报告**的链路，
  且评审能体验；只交截图与说明不满足这一条。
  → 体验环境（局域网方案或公网 HTTPS）必须在 10/12 前决定，不能拖到 10/14。

**演示视频内容**【附件1·第2页】

真实使用过程：用户提出任务 → AI Agent 执行任务 → 生成结果 → 用户应用结果 →
作品如何支撑个人或小团队完成创业相关任务。与【总纲转引·第7页】的分段要求合并执行。

**原创与来源说明**【附件1·第1～2页】【官网·FAQ Q11】

- 须为学生本人或团队原创，不得抄袭、剽窃，**不得直接包装已有商业产品参赛**。
- 使用开源模型、第三方平台、插件工具、外部数据或素材资源，**应在申报材料中说明来源和使用方式**。
  → 交付物：`docs/technology-sources.md`（C07 统稿，A 提供模型/依赖来源，B 提供素材来源）。

**AI 生成内容的合规要求**【官网·FAQ Q13】

AI 生成的资源与方案**必须人工审核**，建立错误修正与风险预警流程，杜绝偏见与违规内容；
严禁代赛、材料造假、场外协助。→ 对应本项目的「人工检查并发布」这一步，是机制不是口号。

**支撑材料（选填，但本项目有素材）**【附件1·第2页】

如已在课程实训、校园创业项目、双创基地、社团实践、教育服务场景或个人创业项目中试用，
可提交用户反馈、应用案例、运营数据、项目成果。→ 本项目的真实试用记录、统计截图、
复盘报告正好对应；**注意脱敏后再提交**。

### 1.6 评审关注重点【附件1·第2页】

场景真实性、功能完整度、智能体能力、OPC 式实践特征、创新性、实用性、展示效果。
优秀作品应做到：问题明确、流程清楚、功能可用、结果可验证。

【官网·FAQ Q14】另说评审从场景适配性、技术规范性、创新优化性、实施显著性、推广适配性
五个维度开展，但**没有公布各维度分值**；总纲 §1.3 的 20/25/20/25/10 是团队自定的映射，
**不能对外说成官方分值**。

### 1.7 淘汰红线【官网·FAQ Q11】

1. 作品抄袭、数据造假、存在知识产权争议；
2. 内容违反法律法规、公序良俗、教育行业规范；
3. 申报材料缺失、格式严重违规且逾期未补正；
4. 同一作品跨组别、跨赛道重复申报。

**出现任意一项直接淘汰。** 本团队对照动作：三人核对只报这一条赛道；材料数字与系统一致；
来源说明齐全；截止前留足时间。
